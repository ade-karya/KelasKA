# Muatan pilihan SMA/SMK — 045/H/AN/2025

Peserta mengerjakan 2 mapel pilihan sesuai prodi/karir. Semua memakai bentuk
PG / PGK-MCMA / PGK-kategori dan tiga level kognitif.

## Bahasa Indonesia Tingkat Lanjut (300–350 kata, kecuali puisi)

Kosakata: khusus + umum, berimbuhan kompleks, abstrak, denotatif, istilah
teknis, konotatif luas, nuansa makna. Kalimat: kompleks berbagai pola,
efektif, logis. Wacana kohesif–koheren, konjungsi antarparagraf, ejaan.

- Tekstual: informasi teks akademik; kalimat tanggapan/respons/kritik sesuai
  norma sosial-budaya; kalimat usulan–masalah–solusi akademik/kerja; karakter–
  peristiwa–latar sastra Indonesia/terjemahan.
- Inferensial: bandingkan nilai budaya–sosial–moral–religius–pendidikan antar
  karya; ungkapkan kembali sastra Melayu Klasik; ubah tabel/grafik ↔ uraian
  akademik/kerja; ketepatan bahasa–kiasan–citraan; ketepatan afiks–frasa–
  klausa–kalimat; kohesi–koherensi teks ilmiah.
- Evaluasi–apresiasi: gagasan antar teks (digital/cetak) via logika; ketepatan
  isi antarteks sosial–akademik–kerja; gagasan/tindakan tokoh via norma–nilai;
  alih wahana puisi → prosa; respons emosional puisi–prosa–drama.

## Matematika Tingkat Lanjut (aljabar, geometri–pengukuran, kalkulus)

- Matriks: determinan, invers, operasi; elemen real; 2×2 atau 3×3.
- Polinomial: operasi, pemfaktoran, suku sisa; orde ≤ 4, koefisien real.
- Fungsi: domain–kodomain–range–grafik polinom (≤4), rasional, akar,
  eksponensial (basis asli), logaritma, mutlak, trigonometri.
- Vektor: bidang–ruang; panjang; operasi; komponen ≤ 3.
- Lingkaran: persamaan + garis singgung; luas–keliling daerah/bagian.
- Transformasi: translasi, refleksi, rotasi, dilatasi + komposisi; titik, garis,
  bangun datar; matriks transformasi.
- Limit: fungsi aljabar + trigonometri; tanpa Teorema L'Hopital.

## Bahasa Inggris Tingkat Lanjut (B2 + B1)

Exposition + discussion; teknologi dan isu faktual. B2: 300–400 kata, ≤4000
kata, kalimat kompleks. B1: 250–350 kata, ≤3000 kata.

- Tekstual: gagasan utama; klasifikasi argumen–fakta–pendapat; peta konsep/
  diagram alir; ringkasan; sintesis lintas sumber.
- Inferensial: detail pendukung; topik–tujuan–pesan moral; hubungan antar-ide;
  sebab-akibat; sudut pandang penulis; prediksi implikasi.
- Evaluasi–apresiasi: fakta vs opini; kredibilitas–cakupan perspektif;
  kesesuaian–kelengkapan–keakuratan (banding sumber lain); kekuatan argumen;
  tanggapan kritis beda sudut pandang.

## Sains

- Fisika: kinematika (GLB/GLBB, parabola horizontal, melingkar beraturan,
  jangka sorong–mikrometer–neraca, angka penting), dinamika (Newton 1–3,
  momentum–impuls, momen gaya–inersia), fluida (Pascal, Archimedes,
  kontinuitas–Bernoulli), gelombang (bunyi, cahaya–cermin–lensa–optik), kalor
  (suhu–wujud–pemuaian–perpindahan, rumah kaca, Boyle–Gay Lussac–gas ideal,
  4 proses termo–mesin kalor), listrik (Coulomb–medan–potensial, Ohm–Kirchoff
  seri-paralel daya). Level: Pemahaman / Penerapan / Analisis–Evaluasi.
  Konteks: fenomena lingkungan, makhluk hidup, teknologi, percobaan.
- Kimia: dasar (atom golongan utama, VSEPR–domain, ikatan ion–kovalen–
  koordinasi–logam–antarmolekul), stoikiometri (mol, Proust, Avogadro, gas,
  kekekalan massa, empiris–molekul, kadar, penyetaraan, pembatas, rendemen),
  organik (alkana–alkena–alkuna), analitik (molar–normal–molal–fraksi–persen,
  koligatif, elektrolit, pH–penyangga–hidrolisis–titrasi–Ksp), fisik (redoks–
  sel, kalorimetri–Hess–entalpi–disosiasi, laju–kesetimbangan). Level:
  Knowing–Applying–Reasoning. Konteks: inquiry, sehari-hari, lingkungan,
  industri.
- Biologi: keanekaragaman Indonesia (klasifikasi, bakteri Gram, ekosistem),
  sel (katabolisme–anabolisme, enzim), transport manusia (sirkulasi–respirasi–
  ekskresi, keterkaitan antarsistem), imun, koordinasi (saraf–hormon),
  reproduksi; KPS (mempertanyakan–merencanakan–memproses). Level:
  Pemahaman / Penerapan / Penalaran.

- Sejarah: pengantar ilmu, Hindu–Buddha–Islam, perlawanan Eropa, pergerakan–
  proklamasi, revolusi–demokrasi terpimpin, Orde Baru–reformasi; sumber

- Antropologi: pengantar–ruang lingkup, etnografi, multikultural, perubahan
