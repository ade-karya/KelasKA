# Muatan wajib SMA/SMK — 045/H/AN/2025

## Bahasa Indonesia (membaca)

Teks informasi tunggal/jamak: fakta, konsep, prosedur, metakognisi; skala
lokal–nasional–global. Teks fiksi: realisme/absurd; latar konkret/abstrak;
tokoh bulat; konflik tunggal/jamak penyelesaian terbuka; alur campuran; POV
campuran.

Karakteristik: kosakata khusus+umum, berimbuhan kompleks, abstrak,
denotatif, istilah teknis, konotatif luas. Kalimat 8–12 kata, kompleks
berbagai pola + inversi. Wacana: konjungsi pertentangan dan sebab-akibat,
tanda baca dukung ungkapan/makna; 250–300 kata (kecuali puisi).

Subkompetensi:

- Tekstual: kata serapan daerah/asing; latar–karakter–fenomena dari kosakata;
  kerangka/bagan bagian penting.
- Inferensial: ide pokok, gagasan pendukung, tokoh, peristiwa, latar, konflik,
  nilai; hubungan makna antarkalimat/paragraf; prediksi lanjutan/akhir.
- Evaluasi–apresiasi: relevansi kehidupan; keakuratan–kesesuaian–kecukupan–
  ketepatan informasi; ketepatan bahasa; ketepatan bagian teks untuk karakter/
  peristiwa/latar fiksi; respons emosional puisi–prosa–drama.

## Matematika (problem solving + logika terintegrasi)

Elemen: bilangan, aljabar, geometri–pengukuran, data–peluang, trigonometri.
Konteks matematika dan keseharian personal/keluarga/lingkungan lokal–global.
Kemampuan: pengetahuan, representasi, penalaran–pembuktian, pemecahan
masalah, koneksi. L3 tambah generalisasi dan justifikasi.

| Elemen | Sub-elemen dan batasan |
|---|---|
| Bilangan | Real incl. asli berpangkat bulat/pecahan; jenis–sifat; operasi + sifat komutatif–asosiatif–distributif |
| Aljabar | SPL multivariabel (maks 3) + pertidaksamaan + program linear; fungsi linear–kuadrat–rasional (domain–kodomain–range, invers, komposisi; analitis dan grafis); barisan–deret aritmetika–geometri (incl. pertumbuhan, peluruhan, bunga tunggal–majemuk) |
| Geometri–Pengukuran | Hubungan sudut–garis–bidang; datar segitiga–segiempat–lingkaran + gabungan segitiga–lingkaran; ruang beraturan sisi datar–lengkung; jarak titik–garis–bidang; sebangun–kongruen; Pythagoras; transformasi (translasi, refleksi, rotasi, dilatasi + komposisi) dari titik; keliling–luas; volume + luas permukaan; jarak objek |
| Trigonometri | sin, cos, tan, cotan, sec, csc |
| Data–Peluang | Penyajian batang–garis–lingkaran–grafik–tabel–visual; pemusatan–penyebaran tunggal–kelompok; pencacahan (penjumlahan, perkalian, permutasi, kombinasi); peluang tunggal + majemuk |

## Bahasa Inggris (membaca, CEFR)

Jenis teks: descriptive, recount, narrative, procedure, analytical exposition.
Konteks sehari-hari, kerja, akademik proporsional; hindari kosakata teknis
jarang. B1: 250–350 kata, ≤3000 kata, kalimat sederhana + kompleks. A2:
200–300 kata, ≤2000 kata, sederhana + beberapa majemuk dasar.

Subkompetensi:

- Tekstual: identifikasi informasi; klasifikasi orang–benda–tempat–peristiwa;
  kerangka/daftar; ringkasan; sintesis lintas sumber.
- Inferensial: detail pendukung; topik–ide–tujuan–pesan moral; urutan kejadian;
  perbandingan; sebab-akibat; karakter tokoh; prediksi akhir.
- Evaluasi–apresiasi: realitas vs fantasi; fakta vs opini; kecukupan–validitas;
  kesesuaian bagian teks; tanggapan isi (tertarik, bosan, gembira, takut).
