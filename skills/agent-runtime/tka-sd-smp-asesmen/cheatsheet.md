# Cheatsheet TKA SD/SMP

## Keputusan cepat

| Jika | Maka | Karena |
|---|---|---|
| Menulis soal membaca yang jawabannya tertulis eksplisit | Tekstual: tersurat / ikhtisar / bagan | Mengukur pemahaman eksplisit |
| Menanya ide pokok, amanat, makna ungkapan, hubungan antarteks, prediksi, kiasan | Inferensial | Mengukur kesimpulan tersirat |
| Menanya relevansi kehidupan, kesesuaian/keakuratan, respons emosional | Evaluasi–apresiasi | Mengukur penilaian dan tanggapan |
| Soal hitung rutin / baca grafik / kelompokkan / identifikasi | Matematika L1 | Knowing and Understanding |
| Soal cerita rutin jadi model / pakai rumus familiar / tafsir makna | Matematika L2 | Applying |
| Konteks baru, kaitkan banyak konsep, nilai strategi, simpulkan, generalisasi (SMP) | Matematika L3 | Reasoning |
| Satu jawaban benar | PG sederhana | Paling hemat untuk L1 |
| Beberapa jawaban benar | PGK MCMA | Uji kelengkapan (contoh: folivora) |
| Klaim per baris perlu dinilai | PGK kategori | Benar/Salah, Sesuai/Tidak Sesuai, Setuju/Tidak Setuju |
| Butir berbagi stimulus | Jenis grup | Hemat stimulus, ukur kedalaman |

## Ambang dan default

- Panjang teks: SD 150–200 kata; SMP 200–250 kata; puisi dikecualikan.
- Kalimat: SD 3–7 kata pola SPOK; SMP 5–9 kata.
- Mata uji: Bahasa Indonesia + Matematika, keduanya dikerjakan.
- Bukan kelulusan: jangan tulis konsekuensi lulus/tidak lulus di kelas.
- Satu butir satu target; metadata selalu di brief.

## Tanda bahaya

- Mengajar hanya yang diujikan → penyempitan kurikulum; TKA hanya sebagian
  kompetensi.
- Stimulus grup bocor ke butir lain → tiap baris PGK kategori independen.
- Distraktor asal-asalan → ambil dari miskonsepsi nyata.
- Kunci ganda format → samakan "KUNCI JAWABAN: X".
- Keluar batasan muatan (mis. diagram lingkaran untuk SD, SPLDV untuk SD) →
  cek references muatan dulu.

## Istilah kunci → lokasi
